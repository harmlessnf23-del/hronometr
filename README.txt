ХРОНОМЕТР НЕДЕЛИ — автономная версия

Как разместить (бесплатно, пара минут):
1. Распакуйте архив — получится папка hronometr.
2. Откройте https://app.netlify.com/drop и перетащите папку hronometr в окно.
   Зарегистрируйтесь (бесплатно), иначе сайт удалится через час.
3. Netlify выдаст адрес вида https://что-то.netlify.app — это ваше приложение.
   В настройках сайта имя можно поменять, например на hronometr-pavel.netlify.app.

Как установить на телефон:
- iPhone (Safari): открыть адрес → «Поделиться» → «На экран „Домой“».
- Android (Chrome): открыть адрес → меню ⋮ → «Установить приложение».
Приложение откроется во весь экран со своей иконкой и будет работать без интернета.

Важно про данные:
- Отметки хранятся только в браузере того устройства, где вы отмечаетесь.
  У телефона и компьютера хранилища разные.
- Раз в неделю: Аналитика → «Резервная копия (JSON)». Восстанавливать там же.
- «Таблица (CSV)» открывается в Excel.
- «Скопировать запрос для разбора в Claude» — вставьте запрос в чат и получите рекомендации.

Обновление приложения: замените файлы, в sw.js увеличьте версию (hronometr-v1 → v2)
и снова перетащите папку на Netlify (раздел Deploys). Данные при этом не теряются.

Другой вариант — GitHub Pages: создать репозиторий, загрузить файлы,
Settings → Pages → Deploy from branch.
Если открыть index.html двойным щелчком, отметки работать будут, но без установки
на телефон и без офлайн-режима: для этого нужен https-адрес.
